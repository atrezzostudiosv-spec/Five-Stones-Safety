# Five Stones Safety — ATREZZO Design Demo V1

**Status:** concept prototype. Not published and not connected to live business systems. English site for North Texas school safety stakeholders.

## Local preview
Open `index.html` with a browser. Keep `assets/` alongside the HTML pages. No build tools necessary.

## Scope
Home, Our Approach, Customer Stories, Resources, Contact / Schedule a Demo, and Technical Support concept pages. Source: authorized capture of fivestonessafety.com and previously produced client presentation prototype.

## Form behavior
All forms run locally, call `preventDefault()` in JavaScript, and display a simulated confirmation dialog. No CRM, email, backend, analytics, or collection endpoint is configured. Entered values are not stored. Contact delivery is deferred until explicit approval.

## Media
Images and PDFs are included from the original website capture. Some are design references; none should be described as the agency’s new installations unless substantiated. Usage rights for third-party marks, outside sources and CENTEGIX materials must be reviewed before public launch.

## Quality
Draft for visual review. Desktop, tablet, and mobile testing required before release. `robots` is intentionally `noindex,nofollow`.
